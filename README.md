# alkalurop/.github

GitHub [organization profile](https://github.com/alkalurop) for **Alkalurops**. The markdown that shows in the org section is [`profile/README.md`](profile/README.md).

Public [ixamal](https://github.com/ixamal) originals are mirrored into same-named repos on this org on the **15th of each month**. This `.github` repo is the bridge landing page, not a mirror of ixamal.

The Mac job is `docs/examples/alkalurop-bridge.sh` in [ixamal/ix](https://github.com/ixamal/ix) (LaunchAgent `ai.ixamal.alkalurop-bridge`, 15th 15:00 local). It uses local `gh` auth. No tokens in git.
